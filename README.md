## Crawling Instruction

The crawling agent should process these websites **in the exact order listed above**, starting from **#1 Salesforce** and ending at **#100 Grain**.

The website / hint column contains the preferred starting URL or documentation/API endpoint for crawling. Where a website is listed as an application homepage, the agent may discover the relevant documentation, API, developer portal, or publicly accessible pages from that domain.

### Crawling Order

1. Process websites sequentially from #1 to #100.
2. Do not reorder websites based on category, popularity, domain, or crawl difficulty.
3. Preserve the numbering and category structure when storing or reporting crawl results.
4. If a website cannot be crawled, record the failure and continue with the next website.
5. Respect each website's robots.txt, terms of service, rate limits, authentication requirements, and other applicable access restrictions.

# AI Product Ops Research Agent

## Run

```bash
pip install -r requirements.txt
cp .env.example .env
python -m src.agent.main --limit 3
python -m src.agent.main --all
```

The agent reads the 100 crawl targets from this README in their existing order.

## Outputs

- `data/results.json` — research results
- `data/verification.json` — verification metrics
- `reports/index.html` — final HTML case study

## Architecture

README → Tavily Search → Web Crawl → Gemma 3 4B → Pydantic Validation → Verification → Analysis → HTML Report
